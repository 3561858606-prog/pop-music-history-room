# v8 本地回归

三个页面都使用独立的测试存储，不读写日常学习记录：

- `tests/`：旧记录导入、并发事务、冲突、回滚、幂等、历史、填空判定。
- `tests/ui.html`：填空草稿、恢复、失败重试、原队列、冲突草稿保留、提前结束和选择题完成。
- `tests/audio.html`：用模拟媒体对象验证播放被阻止、失败重试、缓冲、恢复位置和音频时钟淡入。
- `tests/progress.html`：全部 75 首四项薄弱进度恢复、短历史的答对增长、保存与幂等、实际填空反馈及恢复，以及音频坏档位回退和换源定位。

每页以 `ALL PASS` 为通过标准。音频测试检查状态与调度，不代替耳听验收。

原型数据库为 `v8-proto-learning-v2`，原有 `v8-proto-memory-v1`、`v8-proto-last-round` 和正式学习存储仅用于幂等迁移，保留原始值。新作答与轮次快照在同一 IndexedDB 事务提交，成功后才揭示订正。历史页面可导出包含原始存储快照、所有事件、轮次与冲突草稿的 JSON 备份。

开发服务器支持音频分段与条件缓存。修改服务器脚本后需要重启进程；普通前端代码刷新即可。

## 每首音频的真实波形

- `tests/waveform.html` 验证全部 75 首的匹配关系、峰值聚合、静音、定位边界、键盘操作和换歌，并可手动点击、拖动、播放及切换全部音频。
- `tests/train-waveform.html` 用独立测试数据库验收训练页上的真实波形，不改日常学习记录。
- 波形离线生成至原型自己的 `assets/waveforms/`，每首 4096 段最小值、最大值和 RMS。运行时只请求当前音频的数据，绘制缓存后再按进度着色；未载入时只显示基线。
- `python3 _studio/v8-proto/tools/build-waveforms.py --check` 检查覆盖、源音频 SHA-256、时长和数据范围。更换音频后去掉 `--check` 重新生成（使用系统 Swift / AVFoundation）。原始音频及 v3 波形数据都不改动。

## 同年封套与本地补图

- `tests/sleeves.html` 验证 1967 年 6 张封套在 320/375/640/1024/1280/1440 布局中的独立槽位、实际按钮不重叠、逐张选择、键盘首尾导航、切换年份、75 首本地图像加载，以及原型菜单移除。（唱片页的平面盘已经去掉，WebGL 不可用时舞台上显示说明。）
- 原型 `assets/covers/sources.json` 记录 18 项补配的完整来源和版本关系；`js/cover-overrides.js` 只覆盖原型取图，不修改 `v3/covers.js`。
- 其中 16 项为唱片标签/专辑或合辑图。t21 为 Regal C468 同盘 A 面歌词页（不是《싱싱싱》的 B 面封套）；t52 为同一作品初版乐谱（未识别课程片段的演奏者/发行物）。界面明确标为资料图，不宣称已找到确切录音封套。

## 名称、填空快捷键与音乐史故事

- `tests/reading.html`：逐一用 75 首显示的所有别写实际判分，检查歌名与音乐家别名不混用、错误近似不判对、选项别名与自身对应、HTML 转义、填空方向键与输入法/选字兼容、0 快捷键与含 0 的年份、未知项草稿恢复、防剧透、完整故事与出处覆盖。
- 填空输入框中，未加修饰键的 ←→ 切换四个答题项，首尾循环。空白项按 0 标记没听出并移到下一未填项；已有文字里的 0 正常输入，年份 1900 / 2000 不受影响。Shift + ←→ 保留选字，输入法组合期间不切换答题项。
- 名称显示与填空判定共用 `js/names.js` 的保守名称表。补充了课件旧题名 `황성의 적` 的通行题名 `황성옛터`；不改课件主名、年份与既有得分。
- `js/stories.js` 是原型自己的故事资料。每首含开场、三个章节、直接史料链接与必要的版本注记。完整长读使用原生 details 按需展开；未提交的填空界面不显示答案名称或故事。
